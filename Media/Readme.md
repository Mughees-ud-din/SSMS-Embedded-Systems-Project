## 🎬 Demo Video Contents

The demo video shows the following in order:

1. **Automatic Bell** — Bell triggers automatically at a scheduled time using the RTC
2. **Teacher Mapping Board** — LCD board displays teacher names and lecture number live
3. **Missing Teacher Alert** — Classroom button pressed, principal office LCD updates instantly
4. **Emergency Siren** — Emergency button pressed, siren activates immediately
5. **Keypad Attendance** — Student enters ID on keypad, name and confirmation shown on LCD

---

## 🔧 Hardware in the Photos

- AT89C51 (8051) microcontroller on breadboard
- DS1307 RTC module
- 2× 16x2 LCD displays (1 for principal office + 1 for attendance)
- 1× 20×4 LCD display (for teacher mapping board)
- 4x3 Matrix keypad
- 1× buzzer & LED
- Push buttons (3 classroom buttons + 1 emergency button)
- 5V regulated power supply
